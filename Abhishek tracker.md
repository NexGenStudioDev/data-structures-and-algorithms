# Abhishek tracker

A chapter-wise DSA path from beginner foundations to advanced interview practice, with questions drawn from LeetCode, GeeksforGeeks, and TakeUForward / Striver A2Z. LeetCode is the preferred entry when the same question appears on multiple platforms.

## How to use this tracker

- Follow chapters in order and move from Easy / Beginner to Medium / Intermediate to Hard / Advanced.
- Every external question title opens the source problem. `N/A` marks a local question or solution that is unavailable; check the two local columns separately.
- In Abhishek’s tracker, a row is `Completed` only when a local question and a local answer or solution are both linked.
- In Akanksha’s tracker, every local solution is intentionally `N/A` and every row is `To Do`, while the question list and question links stay the same.
- Chapter 0 is not present in this repository. Chapters 1–5 use foundation self-checks where the external platforms do not offer a directly matching DSA problem.
