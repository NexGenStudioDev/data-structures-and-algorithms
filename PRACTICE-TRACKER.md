# Repository Practice Tracker

One place to find the repository's topic-based practice questions from GeeksforGeeks, TakeUForward's Striver A2Z practice set, and LeetCode. The existing chapter README tables contain the LeetCode roadmaps; their problem names now link directly to LeetCode questions. This page adds distinct GFG and TakeUForward questions and links to the focused Recursion and Traversal trackers, without copying the LeetCode rows a second time.

## Status rules

- **Completed** only when this repository has both a local question document and a local answer/solution document for that exact problem.
- If a local answer is absent, its cell is `N/A` and status is **To Do**.
- A question marked **To Do** is not claimed as solved from profile activity. The linked LeetCode and GFG profiles are reference pages only.
- Difficulty follows the platform label where available. GFG `Basic` is grouped as **Easy**.
- When the same question appears on multiple platforms, keep the LeetCode entry and omit the duplicate GFG or TakeUForward row. Keep each problem under its main topic.
