# Sorting Practice Problems

| Problem | Useful technique |
|---|---|
| LeetCode 912 — Sort an Array | Merge Sort or Quick Sort; state worst-case costs |
| LeetCode 75 — Sort Colors | Three-way partition |
| LeetCode 148 — Sort List | Merge Sort on linked nodes |
| LeetCode 56 — Merge Intervals | Sort by start, then scan |
| LeetCode 268 — Missing Number | Range reasoning, sum, XOR, or cyclic placement under constraints |

Explain why the input constraints fit the chosen sort.
