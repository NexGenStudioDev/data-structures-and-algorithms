# Intermediate Path

**Prerequisites:** Complete the Beginner path or be comfortable with JavaScript functions, arrays, loops, and basic complexity analysis.

**Goal:** Select core data structures and patterns based on the operations a problem requires.

| Order | Chapter | Focus | Checkpoint |
|---:|---|---|---|
| 6 | [Arrays](../Ch-06-Arrays/README.md) | Indexed sequences, prefix sums, and matrix operations | Choose between a direct scan and a prefix-sum approach and explain the trade-off. |
| 7 | [Strings](../Ch-07-Strings/README.md) | String operations, frequency methods, and matching | Explain how immutability and JavaScript string indexing affect an implementation. |
| 8 | [Searching](../Ch-08-Searching-Algorithms/README.md) | Linear search, binary search, and boundaries | State the binary-search invariant and show why each step shrinks the range. |
| 9 | [Sorting](../Ch-09-Sorting-Algorithms/README.md) | Comparison sorts and their trade-offs | Compare time, auxiliary space, stability, and worst-case behavior. |
| 10 | [Two Pointers and Sliding Window](../Ch-10-Two-Pointers-and-Sliding-Window/README.md) | Pointer movement, windows, and intervals | Define what the pointers or window represent before tracing an example. |
| 11 | [Linked Lists](../Ch-11-Linked-Lists/README.md) | Nodes, references, and pointer updates | Safely trace insertion or removal at the head, middle, and tail. |
| 12 | [Stacks](../Ch-12-Stacks/README.md) | LIFO, monotonic stacks, and expression processing | Identify when the most recent unresolved item should be processed first. |
| 13 | [Queues](../Ch-13-Queues/README.md) | FIFO, circular queues, and queue patterns | Trace enqueue and dequeue operations, including wraparound where relevant. |
| 14 | [Hash Maps and Hash Tables](../Ch-14-Hash-Maps-and-Hash-Tables/README.md) | Keyed lookup and frequency counting | Recognize when storing prior values avoids repeated searching. |
| 15 | [Sets](../Ch-15-Sets/README.md) | Membership and uniqueness | Use a set when the needed operation is membership or deduplication. |
| 16 | [Recursion](../Ch-16-Recursion/README.md) | Base cases, smaller subproblems, and call/return flow | Explain what one call returns and how it makes progress toward a base case. |
| 18 | [Trees](../Ch-18-Trees/README.md) | Hierarchy and traversals | Trace preorder, inorder, postorder, and level-order on a small tree. |

**Ready for Advanced when:** you can choose a plausible structure or pattern, explain its invariant, analyze its expected costs, and test edge cases without relying only on a memorized template.

**Bridge topic:** Chapter 17 introduces backtracking and is grouped with the Advanced path because it builds on recursion and adds search-state management and pruning.
