# Beginner Path

**Goal:** Build the vocabulary and programming habits needed to understand and analyze simple algorithms.

| Order | Chapter | Focus | Checkpoint |
|---:|---|---|---|
| 1 | [Introduction to DSA](../Ch-01-Introduction-to-DSA/README.md) | Data, types, structures, algorithms, and trade-offs | Explain the difference between a data type, a data structure, and an algorithm. |
| 2 | [What is an Algorithm](../Ch-02-What-is-an-Algorithm/README.md) | Steps, problem statements, pseudocode, and dry runs | Describe a solution as finite steps and trace it on a small input. |
| 3 | [Basic Programming Questions](../Ch-03-Basic-Programming-Questions/README.md) | Variables, conditions, loops, functions, and basic logic | Write and debug a short JavaScript function using a loop and a condition. |
| 4 | [Time Complexity: Fast vs Slow](../Ch-04-Time-Complexity-Fast-vs-Slow/README.md) | Growth of work as input grows | Explain why elapsed time on one machine is not an algorithmic complexity. |
| 5 | [Time and Space Complexity](../Ch-05-Time-and-Space-Complexity/README.md) | Asymptotic notation, space, and constraints | Estimate the growth of a simple loop or nested loop and state assumptions. |

**Ready for Intermediate when:** you can read a short program, trace variable changes, identify its main repeated work, and explain what happens for empty or small inputs.

**Suggested practice:** solve several basic loop and array exercises from Chapter 3; write down a dry run and a rough time-complexity estimate for each.
