# Learning Paths

[Zero to Monster](./Zero-to-Monster.md) is the full study, exam, and interview roadmap. Use these guides to move through the existing chapter folders at a pace and level that fits your background. The numbered `Ch-XX-*` folders remain the source of chapter content; this folder provides navigation and checkpoints without moving or renaming existing material.

| Path | Start here | Goal |
|---|---|---|
| [Beginner](./Beginner.md) | Chapters 1–5 | Build programming and algorithm foundations and learn to reason about complexity. |
| [Intermediate](./Intermediate.md) | Chapters 6–16, then 18 | Learn core data structures and problem-solving patterns, then work with trees. |
| [Advanced](./Advanced.md) | Chapter 17, then 19–28 and 30 | Study backtracking, advanced structures and algorithms, and mathematical techniques. |

[Interview practice](../Ch-29-DSA-Patterns-and-Interview-Roadmap/README.md) can accompany any path. Revisit earlier chapters whenever a later problem exposes a gap in your fundamentals.

## How to use the paths

1. Read the chapter overview and prerequisites.
2. Work through the concepts in order and trace examples by hand.
3. Implement the algorithm in JavaScript before checking a solution.
4. Explain the correctness idea and complexity in your own words.
5. Move on when you can solve a small variation without copying the example.

The paths organize the curriculum; they do not imply that every listed topic already has a complete lesson. Chapter-by-chapter content remains under development.
