# Interview Question: Square Pattern Printing

**Question:**  
You are given an integer `n` representing the number of rows. Write a program (in C, C++, or Java) to print a **square pattern** of asterisks (`*`) of size `n x n`.  

For example, if `n = 4`, the output should be:
```
****
****
****
****
```

**Requirements:**
- Use **nested loops** (an outer loop for rows and an inner loop for columns).
- The pattern must be a perfect square, meaning the number of rows equals the number of columns.
- Input should be taken from the user (e.g., using `scanf`, `cin`, or `Scanner`).
- Explain how the nested loop structure ensures the square shape is formed.

**Follow-up Questions (Optional for Discussion):**
- How would you modify the code to print a right-angled triangle pattern instead?
- What is the time complexity of this program in terms of `n`?
- How would you handle invalid input (e.g., negative numbers or non-integer values)?
