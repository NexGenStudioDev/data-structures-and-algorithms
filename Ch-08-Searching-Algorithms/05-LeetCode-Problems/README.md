# Searching Practice Problems

Practice in this order. For every problem, first state the input condition that makes the search valid.

| Problem | Main idea |
|---|---|
| LeetCode 704 — Binary Search | Find a value in a sorted array |
| LeetCode 35 — Search Insert Position | Lower bound / first value not smaller than target |
| LeetCode 34 — First and Last Position | Two boundary searches |
| LeetCode 33 — Search in Rotated Sorted Array | Decide which half is ordered; duplicates change the worst case |
| LeetCode 69 — Sqrt(x) | Search the largest integer whose square is at most `x` |
| LeetCode 875 — Koko Eating Bananas | Binary search a monotone answer condition |
| LeetCode 74 / 240 — Search a 2D Matrix | Identify which matrix ordering rule is given |
