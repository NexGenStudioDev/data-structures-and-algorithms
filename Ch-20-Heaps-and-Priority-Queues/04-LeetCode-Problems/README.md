# Heap and Priority Queue Practice

| Problem | Pattern |
|---|---|
| LeetCode 215 — Kth Largest Element | Keep a heap of size `k` or partition |
| LeetCode 703 — Kth Largest in a Stream | Maintain a size-`k` min-heap |
| LeetCode 1046 — Last Stone Weight | Repeatedly remove two largest values |
| LeetCode 23 — Merge k Sorted Lists | Min-priority queue of list heads |
| LeetCode 295 — Find Median from Data Stream | Balance two heaps |

Explain which item belongs at the root and why that is the next useful item.
