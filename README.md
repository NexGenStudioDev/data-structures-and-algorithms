## ⚡ Master Time & Space Complexity Cheatsheet

### Data Structure Operations

| Data Structure | Average Access | Average Search | Average Insert | Average Delete | Worst Search | Worst Insert | Worst Delete | Space Complexity |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **Array** | $O(1)$ | $O(N)$ | $O(N)$ | $O(N)$ | $O(N)$ | $O(N)$ | $O(N)$ | $O(N)$ |
| **Stack** | $O(N)$ | $O(N)$ | $O(1)$ | $O(1)$ | $O(N)$ | $O(1)$ | $O(1)$ | $O(N)$ |
| **Queue** | $O(N)$ | $O(N)$ | $O(1)$ | $O(1)$ | $O(N)$ | $O(1)$ | $O(1)$ | $O(N)$ |
| **Singly Linked List** | $O(N)$ | $O(N)$ | $O(1)$* | $O(1)$* | $O(N)$ | $O(1)$* | $O(1)$* | $O(N)$ |
| **Doubly Linked List** | $O(N)$ | $O(N)$ | $O(1)$ | $O(1)$ | $O(N)$ | $O(1)$ | $O(1)$ | $O(N)$ |
| **Hash Table** | N/A | $O(1)$ | $O(1)$ | $O(1)$ | $O(N)$ | $O(N)$ | $O(N)$ | $O(N)$ |
| **Binary Search Tree** | $O(\\log N)$ | $O(\\log N)$ | $O(\\log N)$ | $O(\\log N)$ | $O(N)$ | $O(N)$ | $O(N)$ | $O(N)$ |
| **AVL / Red-Black Tree** | $O(\\log N)$ | $O(\\log N)$ | $O(\\log N)$ | $O(\\log N)$ | $O(\\log N)$ | $O(\\log N)$ | $O(\\log N)$ | $O(N)$ |
| **Binary Heap** | N/A | $O(N)$ | $O(\\log N)$ | $O(\\log N)$ | $O(N)$ | $O(\\log N)$ | $O(\\log N)$ | $O(N)$ |
| **Trie** | N/A | $O(L)$ | $O(L)$ | $O(L)$ | $O(L)$ | $O(L)$ | $O(L)$ | $O(N \\times L)$ |
| **Graph (Adj List)** | N/A | $O(V + E)$ | $O(1)$ | $O(E)$ | $O(V + E)$ | $O(1)$ | $O(E)$ | $O(V + E)$ |

*\*Insertion and deletion at head/known pointer takes $O(1)$.*

## ⏱️ Input Constraints vs Target Complexity Target

Standard technical interview platforms (LeetCode, Codeforces, HackerRank, GeeksforGeeks) enforce a **1.0-second time limit**, allowing approximately **$10^8$ operations per second**.

| Input Size ($N$) | Target Time Complexity | Expected Algorithm / Paradigm |
|---|:---:|---|
| $N \\le 10$ to $12$ | $O(N!)$ or $O(N^2 \\cdot 2^N)$ | Permutations, Travelling Salesperson (TSP) DP |
| $N \\le 20$ to $25$ | $O(2^N)$ | Exhaustive Backtracking, Bitmask DP |
| $N \\le 100$ | $O(N^4)$ or $O(N^3)$ | 3-loop Brute Force, Floyd-Warshall All-Pairs Shortest Path |
| $N \\le 500$ to $1,000$ | $O(N^2)$ | Nested Loops, 2D Grid DP, Bubble/Insertion Sort |
| $N \\le 10^5$ to $10^6$ | $O(N \\log N)$ or $O(N)$ | Sorting, Binary Search, Sliding Window, Two Pointers, DSU, Segment Tree |
| $N \\ge 10^9$ | $O(\\log N)$ or $O(1)$ | Fast Exponentiation, Binary Search on Range, Math Formula, Bitwise Tricks |

## 📁 Repository Structure & Multi-Platform Convention

The repository supports multiple coding platforms (**LeetCode**, **GeeksforGeeks**, **Codeforces**, **HackerRank**). Follow this clean, standardized directory convention:

```text
Ch-XX-Topic-Name/
├── 01-Topic-Subfolder/
│   ├── README.md               # Concepts, theory & algorithmic intuition
│   ├── code/                   # Reference code implementations (JS / Python)
│   └── .gitignore              # Pre-configured folder gitignore
├── LeetCode/
│   └── Problem-Name/
│       ├── Question.md         # Problem description & constraints
│       ├── Solution.md         # Detailed explanation, dry runs, diagrams
│       ├── code/
│       │   ├── solution.js     # JavaScript implementation
│       │   ├── solution.py     # Python implementation
│       │   └── solution.cpp    # C++ implementation
│       └── images/             # Visual dry runs and trace diagrams
├── geeksforgeeks/
│   └── Problem-Name/
│       ├── Question.md
│       ├── Solution.md
│       └── code/
├── README.md                   # Chapter overview, syllabus, problem roadmap
└── .gitignore                  # Chapter gitignore
```
