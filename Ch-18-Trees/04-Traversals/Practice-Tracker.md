# Binary Tree Traversal Practice Tracker

Use this page for problems whose main task is to produce or reason about a binary-tree traversal. Tree height, diameter, balance, LCA, and graph traversal belong to their own topic trackers and are intentionally not mixed in here.

## How to read the status

- **Completed** means this repository contains both a problem statement and a solution document for that problem.
- **To Do** means a local solution document is not present. `N/A` means there is no local question or answer document yet.
- The difficulty labels follow the linked platform where available. The LeetCode difficulty is used for its rows.
