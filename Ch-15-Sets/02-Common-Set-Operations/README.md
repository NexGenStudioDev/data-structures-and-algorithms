# Common Set Operations

For sets `A` and `B`:

- Union `A ∪ B`: values in either set.
- Intersection `A ∩ B`: values in both.
- Difference `A - B`: values in A but not in B.
- Symmetric difference: values in exactly one set.
- Subset: every value in A also belongs to B.

These operations are usually proportional to the sets' sizes for hash-based built-ins, but exact costs and iteration order are language-specific. Examples are in both language files.
