# Backtracking Practice

| Problem | Main decision |
|---|---|
| LeetCode 78 — Subsets | Include or skip each value |
| LeetCode 46 — Permutations | Choose one unused item for the next position |
| LeetCode 39 — Combination Sum | Choose candidates while tracking remaining sum |
| LeetCode 79 — Word Search | Explore neighbors while marking visited cells |
| LeetCode 51 — N-Queens | Place one queen per row and prune conflicts |
| LeetCode 37 — Sudoku Solver | Try valid digits and undo failed choices |

For each solution, state what the current path represents, when it is complete, and what makes a branch invalid.
