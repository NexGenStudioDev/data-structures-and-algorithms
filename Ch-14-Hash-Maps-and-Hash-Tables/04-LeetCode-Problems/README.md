# Hash Map Practice

| Problem | Pattern |
|---|---|
| LeetCode 1 — Two Sum | Complement lookup |
| LeetCode 242 — Valid Anagram | Character frequencies |
| LeetCode 49 — Group Anagrams | Canonical key or sorted letters |
| LeetCode 146 — LRU Cache | Map plus doubly linked list |
| LeetCode 347 — Top K Frequent Elements | Frequency map then bucket/heap |

Before choosing a map key, check whether it uniquely represents the needed state.
