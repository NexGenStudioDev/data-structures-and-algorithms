# Recursion Practice Tracker

This list is only for problems where recursion is a central part of the task. Tree traversal, graph traversal, and backtracking-only challenges should live in their own topic trackers, even when their solutions happen to use recursive calls.

## How to read the status

- **Completed** means this repository contains both a problem statement and a solution document for that problem.
- **To Do** means a local solution document is not present. `N/A` means there is no local question or answer document yet.
- GeeksforGeeks labels many introductory tasks **Basic**; they are grouped under **Easy** here for a consistent study path.
- Status is based on local files only. It does not infer completion from a public profile.
